2026-09-06，自建双进程 APK，Android 15 / API 35 ARM64 root 模拟器。
参数：`--probe-mode lifecycle --no-clean-oat --no-maps-scan`；未验证 full 模式或其他系统版本。

| 检查 | 结果 |

## 复测要点

测试 APK 和临时日志未纳入仓库，需另行准备双进程、内存 DEX 加载及 JNI 注册样本。

1. 运行贡献指南中的检查；交叉编译 Android 测试二进制后推到设备执行。
2. 检查不同 PID、相同地址的 DEX 是否分别保留，用不同内容样本覆盖串流风险。
3. SIGSTOP 暂停采集，注册 1300 个不同 JNI 方法，再发送 SIGINT、SIGCONT；核对完整方法名集合。
4. 校验 DEX 结构与校验和，对照 APK 哈希；重建方法须由 ART 实际加载执行。
5. 检查无效输入及写入失败的退出码，在独立副本上做基线和回滚对照。

## 已知问题

- 本轮 JNI 自动定位偏移错误；使用当前 libart 实测偏移 `0x885724` 后通过。该值不可跨构建套用。
- 地址、DEX 头和 CodeItem 标识均不变的原地改写仍可能漏采。
- 结构检查不是完整字节码验证；重建方法缺少原始异常表、调试信息，寄存器窗口依赖推断。
- lib Clippy 通过；all-targets 仍有原有 `src/art.rs` 测试的 `identity_op`。
